# tachikindle-sources

Extension repository for TachiKindle. Follows the repo protocol
defined in https://github.com/Darkgoatie/TachiKindle/blob/main/extensions/format/repo-protocol.md

Add this repo's URL in TachiKindle's repo settings screen:
https://raw.githubusercontent.com/brandoncasa1/tachikindle-sources/main

Each entry in index.json points at a .tkext.json file (schema in
schema-1.0.json) -- no Kotlin, no APKs, no JVM anywhere in this repo.
